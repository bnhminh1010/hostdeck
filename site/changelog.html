v0.1.0 first public cut
2026-07 · Initial Public Release
  • Added Core console: Go-only homelab operations dashboard — no Node.js runtime, no npm, no CDN dependencies.
  • Added Monitoring workbench: historical multi-node monitoring with 3-tier SQLite rollups (10s × 48h, 1m × 30d, 15m × 90d) and configurable quota ceiling.
  • Added Actionable overview: production operations brief with health overview and widget customization.
  • Added Interactive shells: container exec shell and confirmed host Bash, both gated by Tailscale identity.
  • Added Logs: optional Loki + Vector search, regex search with result navigation.
  • Added Alerts: configurable alerts with HMAC webhook delivery provider.
  • Added Containers: multi-mount collector and SMART disk polling host-helper (Phase B).
  • Added Workspaces: multi-workspace customization and light theme.
  • Added Platform: multi-arch container images published to GHCR and Docker Hub.
  • Added Adoption: public demo mode (?demo=1) with neutralized identity, demo installer, TCP probes.
  • Added Docs: operations guide, architecture decision records, comparison matrix, migration guide, measured benchmarks.
  • Changed Repositioned as a Tailscale-only operations console; corrected claims in docs.
  • Changed Redesigned UI as a graphite workspace; replaced SYSTEM STATS eyebrow with a semantic accessibility title.
  • Changed Neutralized demo identity before public screenshots (admin@tailnet, home-n-01).
  • Changed Stopped tracking local design documentation in the repository.
  • Fixed UI: backdrop blur reduced 12px → 4px, cyan-glow spread 20px → 8px, double-glow on brand mark removed, layout root max-width 100vw → 100%, gap-based spacing in container lists.
  • Fixed Browser: recent-change click race eliminated; viewer widget controls and settings cancel restored.
  • Fixed CI: Go toolchain and x/ deps patched to clear govulncheck; Loki query bounds refreshed during retries; Vector fixture discovery made deterministic; Pages artifacts isolated across reruns; checks gated after browser regressions.
